こんにちは，B4の高橋です！今回は，12月12日(水)に行われたもくもく会について紹介します．
<!-- folding -->

もくもく会とは，皆が集まって各自もくもくと勉強したり，もくもくと作業したりする会のことです．
前回の様子は [こちら](takahashi-20180830-145818) ．

今回のもくもく会では，New グループのメンバも一緒に開発をしました．

今回のお題は，[Slack](https://slack.com/intl/ja-jp/about) というチャットツールの bot プログラム「Swimmy」への機能追加です．
Swimmy は，4月に B4 が新人研修で開発しました．GitHub のリポジトリは [こちら](https://github.com/nomlab/swimmy) にあるので，気になった方はのぞいてみてください．
以下が今回開発に取り組んだ機能の一覧です．

+ 次ののむにちを書く人は誰か指名する
+ Qiita のトレンドをお昼につぶやく
+ 指定された日付に何かをリマインドする
+ 投票
+ くじ
+ todo を GitHub の Issue に追加する
+ 写真を Slack にアップロードした時に Google Photos にアップロードする

私は，B4 の吉田くんと一緒に，todo を GitHub の Issue に追加する機能の開発を担当しました．
実際の Slack 上でのやりとりをご紹介します．

![Screen Shot 2018-12-25 at 11.12.26.png](https://lh3.googleusercontent.com/-wHhh77tqM28/XCGSYW2zGdI/AAAAAAABAyg/A6Rz3z5lRVEivJcMrP73TmduehBepK2OwCHMYBhgL/Screen%2BShot%2B2018-12-25%2Bat%2B11.12.26.png)

「todo: 」の後にタイトルと本文(オプショナル)を追加して発言すると，GitHub の乃村研のリポジトリに Issue が追加されるようになりました！
