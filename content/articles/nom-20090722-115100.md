<p>最近，Rails や Linux のソースコードを追いかけるために Git
を使う機会が多くなりました．しかし，国内では Git
に関する書籍はまだ少ないです．
いくつかある洋書の中で，これを買ってみました．</p>
<p><a href='http://www.amazon.co.jp/gp/product/0596520123/'>http://www.amazon.co.jp/gp/product/0596520123/</a>
<!-- folding --></p>
<p>この本は，単なるリファレンス本ではなく，
Git が管理するオブジェクトの構造や Git
におけるコミットやマージといった基本的な概念を丁寧に解説してあります．
Git の世界(こころ)を感じることができます．</p>
<p>RCS, CVS, Subversion 
の順でバージョン管理システムに親しんで来た人(私もそう)
にとって，Git のコンセプトには，最初，少なからず違和感を感じます．
Subversion と Git のコマンド対照表を手にすれば，
とりあえず使ってみることはできますが，普通の geek なら，
そのうちフラストレーションを覚えるようになるでしょう．</p>
<p>そういったタイミングでこの本を読むと，Git の流儀が理解できて，
非常にいい気分になります．
読む過程で，昔 CVS に感じていた違和感を思い出しました．
そうあるべきではなく，単に慣れていただけなんですね．</p>
<p>基本的な事柄をきちんと解説してある本を手元に置いて勉強することは，
Web で cheat sheet を探すよりよほど効率がいい方法だと思います．</p>
